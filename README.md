
# Java JDBC Database Connectivity

## Program Name
JDBCExample

## Aim
To write a Java program that connects to a MySQL database
using JDBC, retrieves all user records, and displays them.

## Technologies Used
- Java
- JDBC
- MySQL

## Files
- JDBCExample.java - Main Java program
- schema.sql - Database and table creation
- output_1.png - Program execution screenshot

## Database Details
- Database: mydatabase
- Table: users
- Columns: id, username, email

## Steps to Execute
1. Install Java and MySQL.
2. Execute schema.sql in MySQL.
3. Add the MySQL JDBC driver to the Java project.
4. Configure the database URL, username, and password.
5. Compile and run JDBCExample.java.

## Expected Result
The program displays the ID, username, and email
of each record in the users table.

## Exception Handling
SQLException is handled using a try-catch block.
